# tpt-hyle-test-utils

In-memory `tpt-hyle` store (`mem_store`), a model-checking `Op` type, and proptest strategies for keys, values and operations. Mock transports arrive with Phase 2.

Part of [tpt-hyle](../../README.md). Status: pre-alpha. Work is tracked in [TODO.md](../../TODO.md) and the design is in [spec.txt](../../spec.txt) (RFC 003).
