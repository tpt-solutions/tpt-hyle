# tpt-hyle-cli

Command-line tool to inspect, dump and verify tpt-hyle stores. Currently provides `inspect`, `dump-sync-log` and `verify`. `compact` is not implemented yet.

Part of [tpt-hyle](../../README.md). Status: pre-alpha. Work is tracked in [TODO.md](../../TODO.md) and the design is in [spec.txt](../../spec.txt) (RFC 003).
